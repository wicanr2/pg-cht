# 03 心得：Pacific General 檔案結構解剖

*這一篇寫給想改 mod、寫存檔工具、或單純好奇「1997 年的 SSI 是怎麼裝資料」的人。*

## 一句話總結

Pacific General 承襲 5D General 系列的**「主 exe + 平面資料檔」**架構 —— 沒有引擎/資料分離、沒有 archive container（除了 PFP 系列），大多數資料檔可以**用 hex editor 直接看**。這在 1997 年是慢慢過時的做法（Quake、暗黑 1 已經用複雜壓縮 archive），但對繁中化來說**簡直是天賜**。

## 檔案分佈（v1.1 full）

| 目錄 | 內容 | 檔數 | 大小 | 譯用 |
|---|---|---|---|---|
| root | 主 exe (`PACGEN.EXE`) + patch + no-CD + Windows 安裝殘留 | ~15 | 1.5 MB | exe 內字串表 |
| `data/` | 遊戲核心資料（裝備、地形、campaign 結構、PFP archive） | 15 | 1 MB | 主戰場 |
| `scen/` | 33 個劇本 × 4 檔（`.SCN` `.TIT` `.DES` `.TST`） | 132 | ~3 MB | 標題與簡報 |
| `Maps/` | 88 個 `.MAP` 二進位地圖（部分共用給多個劇本） | 88 | ~5 MB | 內含地名（待查） |
| `bnk/` | 29 個 `.BNK` sound bank + 120 個 `.MEL` MIDI 檔 | 149 | ~15 MB | 不譯 |
| `stream/` | 122 個 `.MUS` streamed audio（人聲、音效） | 122 | ~250 MB | 不譯 |
| `SMACK/` | 34 個 `.SMK` Smacker 影片（開場、結尾、CG） | 34 | ~200 MB | 不譯 |

## 資料檔家族

### PFP archive（`data/*.PFP`）

PFP 是 SSI 自家的簡單 archive 格式，用 `pfp.exe` 工具打包（不在遊戲檔內，只有原始碼有）。從 `data/PFP.TXT`（build script 殘留）可以看到 `TXT.PFP` 是怎麼打包的：

```
-o=txt.pfp
-i=..\text\classes.txt      # 兵種類別
-i=..\text\terrain.txt      # 地形
-i=..\text\nations.txt      # 國家
-i=..\text\bignats.txt      # 大國名稱
-i=..\text\stance.txt       # 態勢
-i=..\text\weather.txt      # 天氣
-i=..\text\latitude.txt     # 緯度帶
-i=..\text\months.txt       # 月份
-i=..\text\research.txt     # 研究項目
-i=..\text\specials.txt     # 特殊能力
-i=..\text\tilefile.txt     # 地圖圖塊索引
```

所以 `TXT.PFP` 就是**這 11 個純文字檔的 concat + index**。要中文化，需要 unpack → 各自翻譯 → repack。unpack 工具在寫（見 `tools/pfp_unpack.py`，實作中）。

其他 PFP：`DAT.PFP` `PAL.PFP` `SHP.PFP` `TIL.PFP` `TNM.PFP` `PFPDATA.IDX` —— 這些是圖檔/調色盤/圖塊，不涉及文字。

### 裝備資料（`data/PACEQUIP.EQP` + `PACEQUIP.TXT`）

配對出現。`.EQP` 是二進位資料表（183 KB），`.TXT` 是**單位名稱純文字清單**（12 KB，1095 行）。

- `.EQP` 每筆固定寬度 record，欄位包含：ID、SPT（攻擊硬度）、MOV（移動）、燃料、彈藥、初始/固定/防空攻擊值、防禦值、生產日期、退役日期、購買價、prestige、運輸方式等。
- `.TXT` 每行對應一個 unit index，內容是名稱（英文）。1095 行裡 **813 個是實際單位、282 個是 `I'm dead` placeholder**（保留給未來擴充 mod）。

詳細解剖見 [04 裝備檔解析](04-裝備檔解析.md)。

### 劇本三檔一組

每個劇本用四個檔：

- `NAME.TIT` — 純文字標題（e.g. `Admiralty Islands`）
- `NAME.DES` — 純文字簡報（Description，1-3 段落）
- `NAME.SCN` — 二進位劇本資料（單位擺放、目標、勝負條件）
- `NAME.TST` — 用途待確認（可能是提示 tips）

**這是本 CHT 專案最容易的部分** —— 33 個 TIT + 33 個 DES 都是純文字，改 encoding + 翻譯 + 存回即可。無需 hex editor、無需 length-preserving trick。

## Maps 目錄與劇本目錄的關係

`Maps/` 有 88 個 `.MAP` 檔，`scen/` 只有 33 個 `.SCN` 檔 —— 為什麼地圖多這麼多？

因為：**多個劇本共用同一張地圖**。例如 `TARA43.SCN` 和 `TARA44.SCN`（塔拉瓦 1943 vs 1944）用同一張太平洋中部地圖，但兵力部署和目標不同。地圖檔獨立管理，劇本檔透過某個 index 引用。

`data/CAMPAIGN.BIN` 則定義戰役樹（哪個劇本贏了進哪個、輸了進哪個）。這是二進位，需要 RE 才能改（見 [04 裝備檔解析](04-裝備檔解析.md) 附註）。

## 對翻譯者的意義

1. **純文字檔（`.TIT` `.DES` `TXT.PFP` 內含）**：直接改，無長度限制。
2. **PACEQUIP.TXT**：對應 index 改行內容，長度略有寬度限制（顯示區）。
3. **PACGEN.EXE 內字串表**：需要 Big5 length-preserving binary patch —— 中文 3 byte（UTF-8）或 2 byte（Big5）通常比英文 1 byte 長，overflow 會蓋掉相鄰字串。這是本 CHT 最技術活的部分。
4. **`.SCN` `.MAP` 二進位**：可能內含地名/城市名，需要**進一步 RE**（放到後續 session）。
5. **音訊與影片**：不譯。（想做完整版本者：**Smacker 影片可以用 [smkextract](https://github.com/kimci86/smk-tools) 抽出來加字幕，但工作量遠大於此 repo 目前規模**，留給後續 upstream mod 者。）
