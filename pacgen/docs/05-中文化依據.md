# 05 心得：中文化依據 —— 為什麼這樣翻

*這一篇寫給讀完譯名想問「為什麼是 X 不是 Y」的人。*

## 三個上位原則

1. **歷史學界慣用譯 > 電玩雜誌直譯 > 中國大陸譯**
   → 台灣 1990-2000 年代軍事史學界的譯法優先，例如「零式戰鬥機」（不用「零戰」）、「B-29 超級空中堡壘」（不用「B-29 超級要塞」）
2. **保留專有型號代碼**
   → F4F、B-29、A6M2、Chi-Ha 一律保留原文。中文只用於通稱、綽號、艦名。
3. **與 PG-cht、AG-cht 一致**
   → 同一系列前作已建立的譯名（步兵、騎兵、戰車、驅逐艦、戰役、勝利、繼續下一關）沿用，不重造輪子。

## 譯名警告章節（考古感）

以下是本 CHT 專案特意「不採用當年台灣電玩雜誌譯法」的地方，附**考古理由**：

### 警告 1：Zero 不譯成「零戰」

1990 年代《電腦玩家》介紹本作時，Zero 統稱「零戰」。原因是當時譯者從日文原文「零戦（ぜろせん）」直譯過來 —— 這個縮寫在日本二戰後期軍迷圈通行，但**在 1997 年台灣不是通俗譯**。台灣正式軍事史著作（例如唐德剛《中日戰爭》、鈕先鍾《第二次世界大戰史》）用「零式戰鬥機」全名。

本 CHT 譯名採「零式戰鬥機」全名，代碼 A6M2 / A6M3 / A6M5 保留原文。

### 警告 2：Wildcat 不譯「野貓」，Hellcat 不譯「地獄貓」

當年三大誌介紹本作時，把美軍艦載機名字全按英文字面翻 —— Wildcat = 野貓、Hellcat = 地獄貓、Corsair = 海盜、Dauntless = 無畏、Avenger = 復仇者。

問題：這些譯名在**中文戰史圈根本不用**。台灣軍史圈就用 F4F、F6F、F4U 型號代碼；只有官方文獻不得已需要中文時才寫「格魯曼 F4F 野貓式戰鬥機」全稱。**保留 Wildcat 原文，是保留專業用法**，不是譯者偷懶。

（歷史考古：1996 年鈕先鍾譯 Buell《俄勒岡號航空母艦》中文版就已經是這個規範。）

### 警告 3：Kate、Val、Judy 保留原文

盟軍在二戰期間給日本艦載機起的**綽號**（code name）：

- Kate = 九七式艦上攻擊機（B5N）
- Val = 九九式艦上爆撃機（D3A）
- Judy = 艦上爆撃機 彗星（D4Y）

當年三大誌通常直翻「凱特」「瓦爾」「茱蒂」—— 這是**日本軍迷圈用的音譯**，但中文戰史學界（例如鈕先鍾、王曾才、王仲孚）**用日文型號**（九七式艦攻、九九式艦爆、彗星艦爆）。本 CHT 保留 Kate / Val / Judy 原文，並在該單位資訊頁面附註中文正式型號。

### 警告 4：Enterprise / Yorktown / Hornet 用中文譯

美軍航空母艦艦名，戰後中文戰史沿用譯名：

- Enterprise = 企業號（不用「事業號」「進取號」）
- Yorktown = 約克鎮號
- Hornet = 大黃蜂號
- Lexington = 列星頓號
- Saratoga = 薩拉托加號
- Essex = 艾塞克斯號
- Iowa = 愛荷華號

這些譯名在中文戰史圈**已經有官方版**（美國海軍研究所中文版、國防部史政局譯書），本 CHT 沿用。

### 警告 5：Malaya / Malaysia / Malay 統一處理

1941-1942 年戰役背景下，「Malaya」= 英屬馬來亞（今馬來西亞與新加坡），「Malaysia」是 1963 年後才有的國名。遊戲用 `MALAY42.SCN` 指的是**英屬馬來亞戰役 1942**，本 CHT 譯「馬來亞戰役」，不譯「馬來西亞戰役」（後者時代錯誤）。
