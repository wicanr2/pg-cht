# 04 心得：PACEQUIP.EQP 裝備檔解剖

*這一篇寫給想懂「為什麼太平洋戰場有這麼多兵種」以及「怎麼看懂資料結構」的人。*

## 檔案配對

太平洋元帥的裝備資料存在兩個檔：

- `data/PACEQUIP.EQP` — 二進位固定寬度表格（183,962 bytes）
- `data/PACEQUIP.TXT` — 單位名稱純文字清單（12,012 bytes，1095 行）

兩檔透過**行號 = record index** 一對一對應。想確認：

```bash
head -1 data/PACEQUIP.TXT     # → "Infantry"
                              # 對應 PACEQUIP.EQP 第 0 筆 record
```

## 為什麼 1095 條裡有 282 條 `I'm dead`

計算：

```
總條目:1095
實際單位:813
placeholder (I'm dead):282
```

`I'm dead` 是 SSI 內部開發時的**佔位標記** —— 資料表預留了 1095 個 record slot，但實際只用了 813 個。剩下 282 個沒填內容，暫時擺 `I'm dead` 讓程式知道「這個 index 存在但無效」。

想改 mod 加自訂單位的人，這 282 個 slot 就是**現成的擴充位**。（不過要對應改 `.EQP` 二進位裡的欄位。）

## 813 個單位分佈

大致分五大類（依 `.TXT` 檔內容抽樣統計）：

- **步兵類（Infantry / Cavalry / Marines / Paratroopers / Engineers）** ~180 條
  - 涵蓋 1936、1939、1941、1943、1945 五個年代切片，每個國家一組
- **戰車類（Light Tank / Medium Tank / Heavy Tank / Tank Destroyer）** ~150 條
  - 太平洋戰場的戰車不如歐洲戰場多樣，主要是美國 Sherman 系列、日本 Chi-Ha / Ha-Go
- **戰鬥機 / 轟炸機（Fighter / Bomber / Torpedo Bomber / Dive Bomber）** ~200 條
  - 太平洋戰場的**主角**。F4F Wildcat、F6F Hellcat、F4U Corsair、P-38 Lightning、B-17、B-25、B-29、Zero、隼、Val、Kate、天山、彩雲…
- **艦艇（Destroyer / Cruiser / Battleship / Aircraft Carrier / Submarine）** ~180 條
  - 5D 系列唯一大量收錄海軍的作品。翔鶴、飛龍、大和、赤城、Enterprise、Yorktown、Iowa…
- **火砲 / 防空 / 特殊（Artillery / AA Gun / AT Gun / Fortification）** ~100 條

## `.TXT` 檔的可讀性

**這個檔案是純 ASCII、每行一個名稱、無 header** —— 對翻譯者友好到不真實。相較之下，同期的其他遊戲（例如世紀帝國）把單位名塞在 DLL resource string table 裡，改起來要 Visual Studio。

抽樣看看檔案風格（前幾行）：

```
Infantry
Cavalry
Aurore
I'm dead
Partisans
```

`Aurore` 是法軍的 Aurore-class 步兵單位（1939 年戰前法屬印度支那駐軍）。`Partisans` 是游擊隊 —— 這款遊戲罕見地包含**非正規軍**單位，因為菲律賓戰場、緬甸戰場的游擊隊在史實上舉足輕重。

## `.EQP` 二進位結構（RE 進行中）

從觀察 `data/REPORT.TXT`（開發階段的 debug dump，SSI 意外留在遊戲目錄裡）可以推出欄位順序：

```
#  NAME  DATE  END  VAL  SPT  MOV  MOVE_MODE  MEDM  FUEL  AMMO  INT  RNG
   AS  AH  AA  AS  AU  BMB  GD  AD  CD  TD  DD  TYP  Transport  CNT  Life
```

每筆 record 大約 168 bytes（183962 / 1095 ≈ 168），欄位包括：

- **識別**：ID、NAME index、DATE（生產日期）、END（退役日期）、VAL（購買價 / prestige 成本）
- **戰鬥**：SPT（攻擊硬度 / soft target）、MOV（移動點數）、MOVE_MODE（Leg / Tracked / Wheeled / Air / Naval / Air Mobile / Airborne）、MEDM（醫療 / 補給類型）
- **後勤**：FUEL、AMMO、INT（威望）、RNG（射程）
- **攻擊力矩陣**：AS（Anti-Soft）、AH（Anti-Hard）、AA（Anti-Air）、AU（Anti-Unit）、BMB（轟炸）
- **防禦力**：GD（Ground Def）、AD（Air Def）、CD（Close Def）、TD（Tank Def）、DD（Diving Def）
- **類型**：TYP（S / A / N / …）、Transport 方式、CNT（單位計數）、Life（生命值）

這解釋了為什麼太平洋戰場的裝備細節如此多樣 —— **AA / AS 攻擊力分開計算**，讓 F4F Wildcat 這種艦載機能同時對付敵艦（AS）和敵機（AA），但對地攻擊（AS） 就不如 SBD Dauntless 俯衝轟炸機。這就是 5D 系列後期作品的特色。

## 中文化選擇

裝備名稱涉及**歷史譯法約定**，本 CHT 專案採以下規範：

- **飛機型號代碼**保留原文：F4F、B-29、Zero A6M2（不譯成「無敵戰車 F4F」）
- **艦名**用中文戰史慣用譯：翔鶴、飛龍、赤城、大和、Enterprise = 企業號、Yorktown = 約克鎮
- **兵種類別**用中文：步兵、騎兵、戰車、驅逐艦、戰列艦、航空母艦
- **國家名**用中文：日本、美國、澳洲、英國、中國、菲律賓、荷蘭
- **單位別稱**保留：Zero 用 Zero（其中文譯「零式戰鬥機」放旁註），Wildcat 用 Wildcat（旁註「野貓」）

原則：**歷史學界慣用譯先於直譯**。1990 年代電玩雜誌把 Zero 譯成「零戰」是不精確的簡稱，正式中文戰史（王曾才《西洋現代史》、SSI 官方戰史書中譯本）用「零式戰鬥機」。

譯法完整規則見 [05 中文化依據](05-中文化依據.md)。

## 對 mod 者的意義

- `.EQP` 是**固定寬度二進位表**，可以用 hex editor 改 stat 值
- `.TXT` 是純文字，改行內容即可
- 想加自訂單位：找一個 `I'm dead` 的 record，改 `.TXT` 名稱、改 `.EQP` 對應 record 內容
- **注意**：某些 stat 有 hardcoded 限制（例如 MOV > 15 會 overflow），改之前先讀 [SSI Panzer General modding guide](https://www.google.com/search?q=panzer+general+eqp+editor)（社群整理，適用整個 5D 系列）
