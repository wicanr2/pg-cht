# 《裝甲元帥2》歷史百科

《裝甲元帥2》(Panzer General II,SSI,1997)是 5D General 系列(繼 PG1《裝甲元帥》、AG《盟軍元帥》、PacGen《太平洋元帥》)的第四款作品,也是全新引擎的次世代之作(詳見 [`../中文化規劃.md`](../中文化規劃.md))。本目錄整理遊戲中出現過的**真實歷史指揮官**與**戰役背景**,是繁中化工作以外的獨立史料整理,供玩家與後續文案 / 手冊撰寫參考。

## 涵蓋範圍

- **[將領.md](將領.md)** —— PG2 各戰役對應的真實歷史指揮官。重點條目:德國(隆美爾、古德里安、曼施坦因、莫德爾、巴爾克、包路斯)、蘇聯(朱可夫、羅科索夫斯基、科涅夫、華西列夫斯基)、英國(蒙哥馬利)、美國(巴頓)、芬蘭(曼納海姆),另有鄧普西、克拉克等次要條目。另說明遊戲內 `NAMES.TXT` 隨機姓名庫的性質,並表列其中 26 個與真實歷史人物同姓的巧合案例。
- **[戰役.md](戰役.md)** —— PG2 五條戰役線(德國「閃擊戰」/「保衛第三帝國」、美國、英國、蘇聯「挺進柏林」)的結構總覽,與 53 個劇本的歷史背景考證,依年代 / 戰場分節;另闢專節說明遊戲著名的**架空(what-if)分支**(英倫登陸、入侵美國本土、直布羅陀之戰等),清楚區隔於真實戰史之外。
- **[戰役.tsv](戰役.tsv)** —— 53 個劇本的結構化清單(所屬戰役、順序、英文標題、中譯、日期、真實/架空分類、一句話簡介)。
- **[NAMES-姓名庫.tsv](NAMES-姓名庫.tsv)** —— `NAMES.TXT` 400 個姓氏的逐筆音譯與真實人物考證備註。

## 內容原則

比照本 repo 既有 [`docs/scenarios/README.md`](../../docs/scenarios/README.md) 的原則:

- **原創繁體中文史實敘述**,基於公共領域二戰史實(維基百科、正式軍史著作、HistoryNet / Warfare History Network 等公開戰史媒體)查證後原創寫成,**不直譯 SSI 版權簡報文字**——遊戲內劇本簡報(`.TXT` 檔)僅作為判定「此劇本對應哪場史實 / 是否為架空設定」的考證依據。
- **台灣軍事史學界慣用譯名**,參見 [`pacgen/docs/05-中文化依據.md`](../../pacgen/docs/05-中文化依據.md):指揮官(隆美爾、朱可夫、蒙哥馬利、曼施坦因、古德里安)、地名(阿拉曼、諾曼第、庫斯克)等沿用既有慣例,不用大陸簡譯。
- **中性客觀文風**,像軍史條目而非行銷文案,避免「完美」「顛覆」等浮誇用詞,不加「用途:」之類導引式標籤。
- **史實與架空分開處理**:PG2 德國戰役後段有著名的「若戰績夠好,可打進虛構的英倫登陸、入侵美國本土」分支,遊戲簡報文字本身即以 "Assuming"、"Hypothetical" 標註,本百科比照原文精神,將這類劇本獨立成節說明遊戲設計,不與真實戰史並列敘述,避免讀者誤把架空劇情當信史。

## 標註慣例

- 一般敘述文字 = 已查證的史實。
- **〔劇本設定提醒〕**:PG2 遊戲設定與史實有落差之處(如「蘇奧穆薩爾米」讓玩家操作史實上未曾參戰的德軍志願部隊)。
- `[待考證]`:尚未找到可靠來源佐證,或多個來源說法不一致之處。
- `(譯名待對齊)`:譯名未與 repo 既有慣例核對,待後續統一。
- 真實人物與 `NAMES.TXT` 隨機姓名庫的重名,一律標「巧合」而非「劇本安排」,避免誤讀成腳本化角色。

## 與 `NAMES.TXT` / `commanders-draft.tsv` 的關係

`NAMES.TXT`(400 行)經拆檔分析與官方 TechDoc 交叉確認,是**依國別分段(德/俄/英/美各 100)的隨機姓名詞庫**,用於程序化產生部隊指揮官姓氏,**不是精選名將名冊**。因此本百科「將領」主體改以「PG2 各戰役史實上真正的指揮官」為主軸(玩家在劇本中對抗或扮演的歷史統帥脈絡),NAMES.TXT 僅作次要表格附註,列出其中約 26 個與真實人物同姓的巧合案例。完整音譯表由另一輪 subagent 產出並核對官方文件確認姓名庫性質,收錄於 [`NAMES-姓名庫.tsv`](NAMES-姓名庫.tsv)。
